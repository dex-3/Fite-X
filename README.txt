# FITE-X Character Select

Open `index.html` in any modern browser.

## Edit characters
Open `index.html` in a text editor and find:
`const fighters = [`

Each character is one object containing:
- name
- style
- age
- country
- height
- class
- bio
- stats
- tone
- glow
- code

The current prototype uses stylized initials instead of external character images, so it works completely offline. You can later replace the portrait area with your own character artwork.
